# Category photos

This directory contains the 41 locally hosted category photos used by the
homepage and category landing pages. Each image is a center-cropped `640×640`
JPEG so the UI does not depend on a third-party image host at runtime.

Source, creator, landing-page, CC0 license and SHA-256 checksum information is
kept in `sources.json`. The photos were discovered through Openverse and are
provided by StockSnap under CC0 1.0. Do not replace a file without updating its
manifest entry and checksum.
